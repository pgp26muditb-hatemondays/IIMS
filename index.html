Setup on a 4 GB laptop
  1. Install Ollama (free, open source) from ollama.com.
  2. Run ollama pull qwen3:1.7b once (or qwen3:0.6b for speed).
  3. Serve this file locally: python -m http.server 8000, then open http://localhost:8000/nonghikai.html. Or set OLLAMA_ORIGINS="*".
  4. Choose Offline AI and press Test. Then turn Wi‑Fi off: Nonghikai keeps working.
